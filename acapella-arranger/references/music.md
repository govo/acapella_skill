# 音乐约定

这份文件只回答一件事：**写音符和混音时该填什么数**。命令怎么调在 `commands.md`。

## 1. 声部表（阿卡贝拉四声部起点）

| 角色 | 音域 | 声像 | 音量 | 节奏 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 人声贝斯 | A1–G3（MIDI 33–55） | 0（居中） | 0.85 | 半音符 / 全音符 | 只走和弦根音，别走旋律 |
| 琶音 / 内声部 | D2–E6（38–88） | ±0.15 | 0.6 | 四分音符 | 从和弦低音起 1-3-5 上行 |
| 长音垫 | 主唱上方 3–8 度 | ±0.25 | 0.5 | 全音符 | 和弦内音，级进优先 |
| 高音和声 | 主唱上方 5–12 度 | ±0.3 | 0.45 | 全音符 | 副歌才进，主歌留白 |
| 主唱 | — | 0 | 1.0 | — | 不改，只做参考 |

`pan` 取值 −1…1（`-0.25` 等价于 `L25`，`0` 是居中）。
`volume` 可以写 `0.85`、`85%` 或 `-1.5dB` —— CLI 三种都接受，服务端只存线性增益。

## 2. 音高怎么写

- 科学音高记号：`C4` = 中央 C = MIDI 60。升号 `#`，降号 `b`：`F#3`、`Bb5`。
- 也可以直接给 MIDI 号：60。
- **越界不会报错，只会难听**：`qc notes` 会标出超出 33–88 的音，交付前必须清零。

## 3. 和弦（写音符时的中间表示，不是 CLI 命令）

这个版本**没有** `chords get/set` 命令。和弦只存在于你的推算里：先定进行，再展开成音符。

支持的记号（`scripts/arrange_from_chords.sh` 认识这些）：

```
C  Cm  C7  Cmaj7  Cm7  Cdim  Caug  Csus4  C6  Cm6
根音可带升降：# / b（F#、Bb）
N = 无和弦（该段留白）
```

音程表（半音）：

| 性质 | 组成 |
| --- | --- |
| maj | 0 4 7 |
| min | 0 3 7 |
| 7 | 0 4 7 10 |
| maj7 | 0 4 7 11 |
| m7 | 0 3 7 10 |
| dim | 0 3 6 |
| aug | 0 4 8 |
| sus4 | 0 5 7 |
| 6 | 0 4 7 9 |
| m6 | 0 3 7 9 |

## 4. 从和弦展开成四声部（脚本用的算法）

给定一小节的和弦根音 `R`（MIDI）与性质音程 `[i₀…iₙ]`：

1. **贝斯**：`R` 降到 A1–G3 内（`while R > 55 { R -= 12 }`），时值 = 整小节（全音符）或半小节（半音符）。
2. **琶音**：从 `R` 起把 `i₀ i₁ i₂` 依次排成四分音符；第二拍起整体升八度直到落进 38–88。
   一小节 4 拍只有 3 个和弦音 → 第 4 拍重复 `i₀`（八度），这是最稳的填法。
3. **长音垫**：主唱音高上方找最近的**和弦内音**，且音程在 3–8 度之间；找不到就降八度找。
4. **高音和声**：主唱上方 5–12 度内最近的**和弦内音**，优先五度。

四条规则都不许出现**平行五度 / 平行八度**（两个外声部同向且音程恒为 7 或 12 半音）。
发现就改内声部：把上方声部反向级进到下一个和弦内音。

## 5. 混音起点

| 参数 | 起点 | 什么时候动 |
| --- | --- | --- |
| 主唱音量 | 1.0 | 不要动 |
| 贝斯 | 0.85 | 低频糊 → 降到 0.7，或 `--volume -2dB` |
| 琶音 | 0.6 | 抢主唱 → 0.45 |
| 长音垫 | 0.5 | 副歌想更厚 → 0.6 |
| 高音和声 | 0.45 | 太尖 → 0.35 |
| 总音量 | 0.9 | 削波时先降这个，别逐轨降 |

`qc mix` 的门槛：峰值 < −0.3 dBFS、`clipped = false`。**先降总音量，再降单轨。**

## 6. 时间与段落

- 时间优先 `bar:beat`（1 起）：`17:3` = 第 17 小节第 3 拍。
- 段落建议 4–8 小节；名字用 `主歌1` `预副歌` `副歌` `桥` `尾奏`。
- AB 循环最小 1 秒（服务端会拒更短的）；练习循环建议 4 或 8 小节整段。
- 改 BPM 会让已写死的秒数位置漂移 —— 用 `bar:beat` 写的不会。

## 7. 这个版本能做什么 / 不能做什么

| 能做 | 不能做（别调用） |
| --- | --- |
| 建工程（BPM/拍号/长度/调性）、加轨、改名、移动、删除 | `fx preset apply`（无此命令；效果器只能靠音量/声像近似） |
| 写 / 改 / 查 / 分析音符 | `midi import` / `midi export`（无此命令） |
| 音量、声像、静音、独奏、折叠 | `chords get/set`（无此命令；和弦信息只在 App 内看） |
| 从人声生成真声合唱 / MIDI 合唱（`harmony` `choir`） | `key analyze`（无此命令；用 `key get` 读，`key set` 写） |
| 渲染 MIDI 轨成音频 | 空工程 `beat set` / `beat analyze`（BPM 建时定死） |
| 走带、AB 循环、分段列表 | 网格 MV 视频（`export --video` 有，网格版不在本版本） |
| 节拍查询 / 分析（导入工程）、重拍 | — |
| 导出混音 / 分轨、客观质检 | — |

没有效果器命令时，"听起来怎么样"只能靠音量和声像 —— 不要向用户承诺压缩、混响、EQ 的效果。
