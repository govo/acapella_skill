# 把人声用起来：元音分配 / 男女配置 / 免费档降级

> 只对**手写阿卡贝拉**（`SKILL.md` 工作流 F）有用。`harmony create` / `choir create` 是机器生成，
> 音色由 App 自己定（非人声），不用看这一页。

---

## 0. 三条硬事实（先看，能省掉三种做错的做法）

**① 一条 MIDI 轨只有一个音色。** `instrumentID` 是**轨级**字段，跟着轨道走，不跟着音符走。
所以「主歌唱呜、副歌唱啊」不是换个参数，是**拆成两组轨**（同一声部两条轨，各管一段），轨数直接翻倍。
> 想让段落之间有对比，**优先改织体**（音区、密度、节奏、力度、声部数），不要动元音 ——
> 改织体不花轨数，改元音要花。

**② 一个音色内部已经是三副嗓子。** 每个元音音色里跑三路刻意失谐的激励，三路的共振峰还各差 20%
（`unisonFormantDrift`）—— 这是为了「多声部不发糊」专门调的。
所以**一条轨的听感 ≈ 三个人唱的小声部**。
> 不要靠复制同音轨来「加厚」：同音叠加只会相位打架、拍频变糊。要更厚就加**不同音**的声部。

**③ 男女声在音色内部已经按响度配平了**（女声 gain 2.0 / 男声 1.70，男声那段注释写明
「换音色不应该换音量」——按 `synth.piano` 的 RMS 对齐过）。所以混音时男女给**同一档轨道音量**就是平衡的。
> 听感上「男声怎么这么小」多半是**元音选错了**（F1 离该声部基频太远），不是音量问题。
> 别用 +3 dB 去补，那只会让低音区糊。

## 1. 八个元音各自擅长什么

共振峰（F1 / F2，女声实测值）决定元音的「身份」，也决定它适合哪个音区。
男声是同一条曲线的男声版，三个共振峰整体下移约 **0.86 倍**（声道更长）。

| 短名 | 女声 id | 男声 id | F1 / F2（女声） | 听感 | 主打用途 |
| --- | --- | --- | --- | --- | --- |
| `ah` 啊 | `synth.choirAh` | `synth.choirAhMale` | 850 / 1130 | 最中性、开口最大、能咬字 | **默认**；主旋律、全团齐唱 |
| `ooh` 呜 | `synth.choirOoh` | `synth.choirOohMale` | 365 / 700 | 暗、圆、空灵 | 底层垫、主歌、氛围 |
| `oh` 噢 | `synth.choirOh` | `synth.choirOhMale` | 500 / 810 | 比「啊」暗、比「呜」开 | 情绪垫、预副歌 |
| `mm` 嗯 | `synth.choirMm` | `synth.choirMmMale` | 280 / 1150 | 最暖、最低、鼻音哼鸣 | 最底层暖垫、尾奏、桥段留白 |
| `aya` 啊呀 | `synth.choirAya` | `synth.choirAyaMale` | 780 / 1400 | 偏前、偏亮但不刺 | 装饰音、快速跑句 |
| `ee` 咦 | `synth.choirEe` | `synth.choirEeMale` | 290 / 2140 | 全系最亮 | 高音声部、副歌高点 |
| `oohoh` 哦呜 | `synth.choirOohOh` | `synth.choirOohOhMale` | 430 / 760 | 气声最多（0.045），化在混音里 | 流行风的「ooh」背景垫 |
| `hey` 嘿 | `synth.choirHey` | `synth.choirHeyMale` | 500 / 1860 | 起音最利落（50 ms / 18 音分） | 节奏重音、断奏、切在鼓点上 |

### 元音 × 声部的适配（● 最实 / ◐ 可用 / ○ 发薄，尽量别让主力音落在这里）

| 元音 | Bass E2–E4 | Tenor C3–A4 | Alto F3–F5 | Soprano C4–C6 |
| --- | --- | --- | --- | --- |
| `mm` | ● | ◐ | ○ | ○ |
| `ooh` | ● | ● | ◐ | ○ |
| `oohoh` | ◐ | ● | ◐ | ○ |
| `oh` | ○ | ◐ | ● | ◐ |
| `ah` | ○ | ◐ | ● | ● |
| `aya` | ○ | ◐ | ◐ | ● |
| `ee` | ○ | ○ | ◐ | ● |
| `hey` | ○ | ◐ | ◐ | ● |

怎么读这张表（依据，不是感觉）：**元音的「厚度」来自 F1 是否落在该声部基频附近**。
Bass 的基频是 82–330 Hz（E2–E4），离 `mm` 的 F1 280 最近 → 最厚；离 `ah` 的 F1 850 最远 →
只能靠泛音撑，听感就是「远、薄、像另一间屋子传来的」。
Soprano 的基频是 262–1047 Hz（C4–C6），正好跨过 `ah` 的 F1 850 → 最实；让它唱 `mm` 就只剩气和鼻音。

> 这张表是**倾向**，不是禁令。全团统一唱 `ee` 时低音薄是正常的（真实合唱团也薄），
> 可以用「低音在这段少动、只唱长音」来绕，不必为了厚度破坏统一。

## 2. 男女怎么配（选声部，先定这个再写音符）

| 配置 | 轨 | 什么时候用 | 备注 |
| --- | --- | --- | --- |
| **SATB**（2 女 2 男） | S / A / T / B | **默认**，标准混声合唱 | 音域覆盖最全，四部和声最好写 |
| SSA + 1 男 | S1 / S2 / A + T（或 B） | 女声为主的流行、民谣、童声感 | 女声叠两层更容易「亮」，但低频要靠 `ooh`/`mm` |
| TTB + 1 女 | T1 / T2 / B + S（或 A） | 男声合唱、低沉、教会风 | 女声只做点缀，别让她一直唱最高音 |
| 二声部 | 高 + 低（各 1 条） | 免费档轨数不够、或只要个底 | 高低相距三度到六度，别只差一个八度 |
| 人声 + 器乐 | 人声 × N + `synth.bass` 等 | 要清晰低频、或不要「纯人声」 | 一旦加器乐就**不是**纯阿卡贝拉了，先跟用户确认 |

**男女比例不是 1:1 硬规矩。** 决定它的是「谁在承托低频」：

- 低音声部必须有男声（`--voice male`）。让女声唱 Bass 音域（E2–E4）不是不能出声，是听着不像人。
- 女声数量 ≥ 2 时，高音区会更「亮」也更薄 —— 用 `oh` 代替 `ah` 能把亮度收回来。
- 只有 1 个男声时，把他放在 **Bass** 而不是 Tenor：无伴奏织体里低频是地基，内声部可以省。

轨数和人数怎么定：

| 轨数 | 建议分配 | 说明 |
| --- | --- | --- |
| 2 | 1 女（高）+ 1 男（低） | 最小可用；只写两个声部，别想着塞满 |
| 3 | 2 女 + 1 男（S / A / B） | 男声当 Bass，女声分高、中两条 |
| 4 | **2 女 + 2 男（SATB）** | **甜点**：四部和声写得开、间距好控、轨数额度也够 |
| 5 | 3 女 + 2 男（S1 / S2 / A / T / B） | 女声分两层做「厚高音」；S1/S2 别同度齐唱，差三度或六度 |
| 6+ | 两套 SATB 或加 Doo 声部 | 容易撞音、平行五度成倍增加；先确认轨数额度够不够 |

> 轨数越多 ≠ 越像合唱团。4 条写对了比 8 条挤在一起更像人 ——
> 每个音色内部已经有三副嗓子（§0 ②），厚度不靠堆轨。

## 3. 元音怎么定（按这个顺序判，别跳）

1. **用户指定了** → 照用户的。用户说「用呜」，就全团 `ooh`；说「副歌要亮一点」，就 `ah` 或 `ee`。
   不要因为你觉得另一个更好听就换掉 —— 这是他编的曲。
2. **免费档**（`instrument list` 的 `pro = false`）→ 只有 `ah`（男女各一份）。见 §4 方案 C。
3. **纯人声、要听起来像一支合唱团** → **全团同一个元音**，默认 `ah`。
   > 这是这一页最重要的一条：真实合唱团同一时刻唱同一个字。
   > 四个声部各唱各的元音，听感立刻变成「四个合成器」而不是「一支队伍」。
4. **按风格挑主元音**（整首一个）：

   | 想要 | 选 | 理由 |
   | --- | --- | --- |
   | 稳、像人、能咬字 | `ah` | F1/F2 居中，四个声部都成立 |
   | 空灵、往后缩、不抢主唱 | `ooh` | 极暗极圆，气声多 |
   | 暖、低沉、像哼着 | `mm` | F1 最低，最暗，铺最下面 |
   | 情绪、铺垫、往副歌推 | `oh` | 卡在「啊」和「呜」中间 |
   | 流行、有空气感 | `oohoh` | 气声最多，化在混音里 |
   | 亮、副歌高点、穿透 | `ee` | F2 2140，全系最亮（低音会薄） |
   | 节奏、断奏、切鼓点 | `hey` | 起音 50 ms，最利落 |
   | 装饰、跑句 | `aya` | 偏前偏亮，短音清楚 |

5. **要段落之间换元音** → 只能拆轨。做法：同一声部建两条轨（`Soprano-verse` / `Soprano-chorus`），
   各写自己那段的音符，各自设音色。**代价**：轨数翻倍、混音要自己接、免费档基本装不下。
   > 想省事就别换元音，改织体：主歌只留 A+T 长音、副歌四声部全开 —— 对比一样出得来。

## 4. 三条预设方案（可直接抄）

### 方案 A · 标准 SATB，全团「啊」（默认，最稳）

```bash
acapella instrument list                       # 0 先看档位：pro / lockedVowels
acapella choir voices                         # 1 音域表（Bass E2–E4 … Soprano C4–C6）
acapella project create "A Cappella" --bpm 96 --beats-per-bar 4 --bars 32 --key C
acapella track add --kind midi --name Soprano
acapella track add --kind midi --name Alto
acapella track add --kind midi --name Tenor
acapella track add --kind midi --name Bass

# 2 先定音色，再写音符 —— 顺序反了会白渲染一次
acapella track instrument <Soprano> ah --voice female
acapella track instrument <Alto>    ah --voice female
acapella track instrument <Tenor>   ah --voice male
acapella track instrument <Bass>    ah --voice male

# 3 写音符（每写一条自动重渲染该轨）
acapella notes replace <Soprano> --notes @soprano.json
acapella notes replace <Alto>    --notes @alto.json
acapella notes replace <Tenor>   --notes @tenor.json
acapella notes replace <Bass>    --notes @bass.json

acapella qc notes && acapella qc mix
```

### 方案 B · 暗色垫，全团「呜」（空灵、往后缩）

同方案 A，只把四行 `track instrument` 的 `ah` 换成 `ooh`。
代价：Bass 唱 `ooh`（F1 365）反而更厚，但 Soprano 会明显薄 —— 所以**旋律尽量交给 Alto / Tenor**，
Soprano 只唱长音，或者干脆只用三条轨（S 缺席，最高声部由 Alto 顶）。

### 方案 C · 免费档（只有「啊」）

**C1 · 纯人声四声部** = 方案 A（它本来就全用 `ah`，免费档原样可做）。注意低音会偏薄。

**C2 · 三条人声 + 一条器乐贝斯**（低频实、更像个成品，但**不是纯人声**）

```bash
acapella track instrument <Soprano> ah --voice female
acapella track instrument <Alto>    ah --voice female
acapella track instrument <Tenor>   ah --voice male
acapella track instrument <Bass>    synth.bass      # 非人声，免费全开
```

选哪条**先问用户一句**（"要不要保留纯人声？"），因为这决定成品算不算阿卡贝拉。
免费档**不要**试 `ooh` / `ee` / `mm` —— 会 `LIMIT_REACHED`（`vocal_vowel_pro`），白跑一轮。

## 5. 混音：比例与声像

| 参数 | 起点 | 什么时候动 |
| --- | --- | --- |
| 外声部（S / B） | 0.80 | 领唱感不够 → 0.9 |
| 内声部（A / T） | 0.65 | 太糊、盖住外声部 → 0.55 |
| 声像 | S −0.25 / A −0.10 / T +0.10 / B +0.25 | 女左男右铺开；四个都居中会挤成一团 |
| 总音量 | 0.9 | 削波时先降这个，别逐轨降 |

三点：

1. **男女不要分开调音量**（音色内部已配平，见 §0 ③）。要改平衡就改元音或改声部数。
2. **力度（velocity）当配器**：内声部 0.55–0.7、外声部 0.75–0.9。四条都 0.8 听起来像管风琴。
3. **先 `qc mix` 再看别的**：`peak < −0.3 dBFS`、`clipped = false`。加了人声元音之后整体会比器乐版更响，
   常常需要把总音量从 0.9 降到 0.85。

## 6. 用户没提音色时，你怎么做

**不要停下来问一堆。** 按默认做完，交付时说**一句**，把选择权交回去：

> 「四条声部我用了全团「啊」（S/A 女声、T/B 男声）——这是最稳的默认。
> 想换元音（呜 / 噢 / 嗯 / 咦 / 哦呜 / 嘿 / 啊呀）告诉我，一句话就能整首换。」

要主动开口的只有这四种情况：

| 情况 | 为什么必须说 |
| --- | --- |
| 免费档，用户要「不同元音」 | 做不到，做完才报错是浪费一轮 |
| 用户要「纯人声」，但低音明显发薄 | 建议加 `synth.bass` 或降成三声部，由用户选 |
| 用户要「段落之间换音色」 | 要拆轨、轨数翻倍，先确认再动手 |
| 用户明确说了音色 | 照做，**并且不要"顺手优化"成你喜欢的那个** |

## 7. 反面清单

- ❌ **四个声部各用一种元音**（Bass `mm` + Tenor `ooh` + Alto `ah` + Soprano `ee`）当「音色分层」交付 ——
  那不是合唱团，是四个音色各唱各的。真要分层，那是背景垫，不叫阿卡贝拉，得跟用户说清。
- ❌ **按段落换元音却不拆轨** —— 一条轨只有一个 `instrumentID`，换不动；写了也只会渲染成同一个音色。
- ❌ **复制同一条轨来"加厚"** —— 每个音色内部已经是三副嗓子，同音叠加只会变糊。
- ❌ **给免费用户写 `--instrument ooh`** —— 只有「啊」免费。
- ❌ **看到男声「听着小」就 +3 dB** —— 先检查是不是让男声唱了高 F1 的元音（`ee` / `ah`）。
- ❌ **把 Bass 声部交给女声**去避免"男声不够" —— E2–E4 是男声音域，女声唱出来不像人。
