# 第一次用：用户不知道怎么开口

装好 skill 之后，用户最常发来的是一句几乎没有信息量的话 ——「试试」「帮我做个歌」
「这个怎么用」。此时你的任务**不是展示工具**，是把他推进到"能听见声音"的那一步。

## 开场三问（一次只问一个）

不要一口气抛出三个问题，也不要把 65 个工具报一遍菜名。按顺序问，每个问题都带选项：

1. **从零开始，还是改现在这个工程？**
   有工程就先 `state` 看，别假设它是空的 —— 空工程的 BPM 是建时定死的，改不了。
2. **想要什么速度、什么调？**
   对方说"随便"就给默认值（100 BPM / 4-4 / C 大调）并**说出来**，让他有机会否掉。
3. **要几个声部？**
   四声部 / 只要低音 / 只要合唱，三选一。别问"你想要什么编配"——他答不出来。

问完给一句计划（建什么、几轨、大概什么样），然后直接做。**不要**再要一次确认。

## 不问也能开工的默认值

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 速度 / 拍号 | 100 BPM / 4-4 | 空工程建时定死，事后 `beat.set` 会 `UNSUPPORTED` |
| 长度 | 16 小节 | 旋律通常 8–16 |
| 调性 | C 大调 | `project.create` 的 `key` 参数 |
| 声部 | Lead / Harmony(三度) / Bass(根音) / Arp(分解) | 四条 MIDI 轨 |
| 混音起点 | Lead 0.75 · Harmony 0.52 · Bass 0.68 · Arp 0.42 | 音量大到能听清，还不打架 |

用默认值时必须说一句「我先按 100 BPM、C 大调、四声部做一版，不喜欢再改」。
默默替用户决定，比问一句更让人不安。

## 这些话分别对应什么

用户不会说得这么整齐，认**意图**不认字面；认不出来就问一句，别猜着改。

| 用户说 | 你调什么 |
| --- | --- |
| 建个 100 BPM 的 C 大调工程，16 小节 | `project.create`（BPM / 拍号 / 长度 / 调性**一次给全**） |
| 这个工程现在什么样 | `state` |
| C Am F G 编成四声部 | `scripts/arrange_from_chords.sh` → `track.add` → `notes.replace` |
| 给主旋律加个三度和声 | `key.set` → `key.get` → `harmony.create type=thirdAbove` |
| 来个人声合唱，低音走四分音符 | `choir.create part=bass.quarter` |
| 这条太响了，降 3 dB，往左偏一点 | `track.mix volume="-3dB" pan=-0.2` |
| 副歌 17–25 小节设成循环 | `loop.set a=17:1 b=25:1` |
| 导出一版混音 | `export.mix` → `GET /download/<downloadId>` |
| 这版混音有没有问题 | `qc.mix`（或 `scripts/qc.sh`，阈值不过退出非 0） |
| 把这首词填进去 | `lyrics.set` |
| 歌词整体早了 0.3 秒 | `lyrics.offset -0.3` |
| 把鼓换成我给的这段 | `POST /upload` → `track.audio.replace` |

## 第一次跑通的最短路径

目标是**先出一版能听的**，不是一版完美的编配：

1. `state` —— 确认连上、看当前工程
2. `project.create` —— 一次给全速度 / 拍号 / 小节 / 调性
3. `track.add` × N —— 几条 MIDI 轨
4. `notes.replace` —— 每轨音符（`scripts/arrange_from_chords.sh` 能直接从和弦生成）
5. `track.render` → `export.mix` → `qc.mix` —— 出声音、出成片、过质检

做完把结果说出来：「四条轨、42 个音符、导出在 <路径>，峰值 -1 dBFS」。
用户能听见东西，才会提下一步要求。

## 不要说、不要做

- **不要报菜名**：「我可以做 A、B、C、D…」——他只想知道下一步说什么。
- **不要一次问三个问题**，也不要用「请告诉我你的需求」这种空话。
- **不要在没被要求时删轨、删工程、覆盖已录 take**，破坏性操作要先问人。
- **不要承诺真声合唱**：人声音色与真声合唱已下架，`choir.*` 生成的是 MIDI 乐器声部，
  别对用户说成"用你的声音唱"。
- **不要凭名字猜轨道 token**：以 `track.list` / `state` 为准，重名会报歧义。
